# SaaS-Skript

Paar aastat tagasi tehtud semi-SaaS pipeline'iga Pythoni'i skript.
Tegin siis selle, et saada abi mängus nagu Rainbow Six Siege aastaid tagasi. Mõtlesin, et miks mitte müüa seda ja teeinisin natukene kommiraha läbi Discordi kasutades Stripei.
Ärge judge'ige seda koodi ma ei teadnud mida tegin siis veel eks.


Lisasin ka main-2.py mis on siis see Discordi bot mis jagas võtmeid ringi.
